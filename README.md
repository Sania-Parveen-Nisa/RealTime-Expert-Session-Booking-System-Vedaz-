# VedazConnect – Real-Time Expert Booking System

A full-stack web application that allows users to book sessions with experts in real-time.

---

## 🚀 Features
- Browse experts
- Book available time slots
- Real-time updates using Socket.io
- Manage bookings (Confirm, Complete, Cancel)
- Email-based booking search

---

## 🛠 Tech Stack
- Frontend: React (Vite), Styled Components
- Backend: Node.js, Express
- Database: MongoDB
- Real-time: Socket.io

---
